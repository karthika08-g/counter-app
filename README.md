# React Counter Application

A simple and interactive Counter Application built using React.js and the useState Hook.

## Features
- Increment counter value
- Decrement counter value
- Reset counter to zero
- Prevent negative values
- Dynamic UI updates
- Responsive design

## Technologies Used
- React.js
- JavaScript
- HTML
- CSS
- Vite

## React Concepts
- Functional Components
- useState Hook
- Event Handling
- Conditional Rendering

## How to Run
1. Clone the repository.
2. Run `npm install`.
3. Run `npm run dev`.
4. Open the local URL in your browser.
